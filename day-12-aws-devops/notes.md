# Day 12: AWS for DevOps

## Topics Covered
- AWS Core Services for DevOps
- Infrastructure as Code with AWS CloudFormation
- CI/CD with AWS CodePipeline and CodeBuild
- Container Services: ECS, EKS, Fargate
- Monitoring and Logging: CloudWatch, X-Ray
- AWS DevOps Best Practices
- Cost Optimization Strategies

## Key Concepts

### Infrastructure as Code
- AWS CloudFormation templates
- CDK (Cloud Development Kit)
- SAM (Serverless Application Model)
- Template parameters and mappings
- Nested stacks and cross-stack references

### CI/CD Pipeline
- CodeCommit for source control
- CodeBuild for build and test
- CodePipeline for orchestration
- CodeDeploy for deployment strategies
- Integration with GitHub and third-party tools

### Container Services
- Amazon ECS (Elastic Container Service)
- Amazon EKS (Elastic Kubernetes Service)
- AWS Fargate for serverless containers
- Container registries (ECR)
- Service discovery and load balancing

### Monitoring & Observability
- Amazon CloudWatch metrics and logs
- Custom metrics and dashboards
- CloudWatch Alarms and Events
- AWS X-Ray for distributed tracing
- CloudTrail for audit logging

### Configuration Management
- AWS Systems Manager (SSM)
- Parameter Store for configuration
- Session Manager for secure access
- Automation documents
- Patch management

## Best Practices
- Use IAM roles instead of access keys
- Implement least privilege access
- Enable MFA for all users
- Use VPCs for network isolation
- Implement backup and disaster recovery
- Regularly audit security configurations
- Use tags for cost allocation
- Implement blue/green deployments
