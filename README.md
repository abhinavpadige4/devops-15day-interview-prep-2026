## How to Use This Plan

1. Each day contains:
   - **Topics**: Key concepts to study
   - **Resources**: Curated learning materials with URLs
   - **Hands-on Exercises**: Practical tasks to complete
   - **Solutions**: Reference implementations/commands

2. Complete the exercises and compare your solutions with the provided ones
3. Push your solutions to the respective day-X/ directories
4. Review and revise on Day 15
